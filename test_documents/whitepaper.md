# 本地知识库系统技术白皮书

## 1. 系统概述

本地知识库（Local Knowledge Base）是一个完全离线运行的 RAG（检索增强生成）系统，专为重度知识工作者设计。

### 1.1 核心特性

系统具备以下核心特性：

- **完全本地化**：所有数据处理在本地完成，无需联网
- **可解释性**：每个答案都带有可溯源的引用
- **隐私优先**：用户数据不会离开本地设备
- **多格式支持**：支持 PDF、Markdown、DOCX 等多种格式

### 1.2 技术架构

系统采用分层架构设计：

1. **解析层**：文档格式解析与结构化
2. **索引层**：双通道检索（BM25 + 向量）
3. **检索层**：混合检索与重排
4. **生成层**：本地 LLM 驱动的 RAG

## 2. 核心模块

### 2.1 文档解析

支持多种文档格式：

- PDF：基于 PyMuPDF 的高性能解析
- Markdown：原生支持，保留结构
- DOCX：Microsoft Word 文档
- HTML：网页内容抽取

### 2.2 层级切片

采用层级切片策略（Hierarchical Chunking）：

```
Document
├── Chapter 1
│   ├── Section 1.1
│   │   └── Chunk 1 (300-600 tokens)
│   └── Section 1.2
│       └── Chunk 2
└── Chapter 2
    └── ...
```

每个切片保留完整的层级路径，便于溯源。

### 2.3 混合检索

检索策略：

1. **BM25 倒排检索**：关键词精确匹配
2. **向量语义检索**：语义相似度匹配
3. **并集召回**：取两者 top-K 的并集
4. **规则重排**：基于密度、位置、时间衰减

### 2.4 引用对齐

每个生成的答案都包含引用信息：

```json
{
  "answer": "系统采用分层架构...",
  "citations": [
    {
      "chunk_id": 42,
      "file": "whitepaper.md",
      "page": 2,
      "text": "系统采用分层架构设计..."
    }
  ]
}
```

## 3. 性能指标

### 3.1 检索性能

- Recall@20 ≥ 0.70（MVP 基线）
- 检索延迟 p95 ≤ 500ms

### 3.2 RAG 性能

- 端到端延迟 p95 ≤ 10s
- 引用准确率 ≥ 80%

### 3.3 解析性能

- 单文档（100页）解析 ≤ 30s
- 支持并行处理（多核）

## 4. 安全与隐私

### 4.1 默认离线

系统默认完全离线运行：

- 模型本地部署（Ollama）
- 无外部 API 调用
- 数据不出本地

### 4.2 审计日志

所有敏感操作记录审计日志：

- 外部 API 调用（如果开启）
- 模型推理记录
- 文件访问记录

### 4.3 数据加密

支持数据库加密（可选）：

- SQLCipher 加密数据库
- 向量库加密存储
